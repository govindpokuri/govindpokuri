## Selected work

### Ansora AI — from desktop application to managed service

Built a Windows AI assistant with local caller transcription, resume-aware answer
suggestions and a text-and-code workflow. Intended for practice, accessibility
and conversations where assistance is permitted.

- **Desktop:** C# / WPF, local Whisper, a configurable overlay and call exports.
- **AI integration:** Azure endpoints, contextual prompts, output limits and model fallback.
- **Managed service:** email OTP, purchased token credits, payments, usage tracking and an admin portal.
- **Open source:** MIT Community edition, bring-your-own AI configuration, setup guides and a Windows portable preview.

[Browse the source](https://github.com/govindpokuri/ansora-ai) · [Try the Community preview](https://github.com/govindpokuri/ansora-ai/releases) · [Use the managed service](https://www.ansora-ai.com/)

## How I build: AI-assisted development

I combine my .NET experience with **AI-assisted development (vibe coding)** to
prototype, debug and refine products. With Codex, I describe the problem, work
through implementation choices, check the result and iterate from real usage.

Ansora AI shows that progression:

1. **Prototype:** a Windows assistant with caller transcription and AI answers.
2. **Refine:** improve answer tone, question handling, UI responsiveness and token controls.
3. **Productize:** add sign-in, payments, usage balances, email, administration and installer/update flows.
4. **Share:** prepare the MIT Community edition, configuration examples, documentation, automated checks and a portable release.

I use AI to accelerate implementation while keeping responsibility for code
review, testing, configuration and release decisions.
