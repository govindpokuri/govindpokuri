## Featured project: Ansora AI

An AI interview assistant for Windows, designed for practice, accessibility and
conversations where assistance is permitted.

- Live caller transcription using local Whisper, with contextual answer suggestions.
- Resume-aware responses and a text-and-code workflow for pasted questions.
- A configurable overlay, call exports and supported Windows screen-capture exclusion.
- A managed service with email OTP sign-in, token balances, payments and an admin portal.
- An MIT-licensed Community edition with bring-your-own AI configuration.

**Stack:** C# / WPF, .NET, Whisper, Azure AI, PHP, MySQL, Razorpay and transactional email.

[Source and setup](https://github.com/govindpokuri/ansora-ai) · [Community Windows preview](https://github.com/govindpokuri/ansora-ai/releases) · [Managed version](https://www.ansora-ai.com/)
